# 公司 HiAgent 导入与验收

## 一、取得环境参数

### 工作空间ID
- 位置：进入目标 HiAgent 工作空间，在已有原生导出 YAML 中确认 WorkspaceID。
- 成功信号：值不再是占位符，且属于准备导入的同一工作空间。

### 模型ID与模型名称
- 位置：在目标工作空间选择实际可用模型，从原生导出 YAML 的 ModelMap 确认 ID 和 Name。
- 成功信号：两者与目标平台原生导出中的同一模型一致。

## 二、本地生成

运行：python scripts/hiagent_workflow.py generate --spec <规格.json> --profile <环境.json> --output-dir <输出目录>

成功信号：退出码0；输出 .yaml 和 .validation.json；status 为 pass。

## 三、导入 HiAgent

- 位置：目标工作空间的工作流管理页面，选择导入工作流。
- 文件：只选择生成的 .yaml。
- 成功信号：平台进入工作流画布，节点连线完整。

## 四、逐节点检查

1. Start：字段名称、必填状态和附件类型与规格一致。
2. Code：输入变量来源正确；试运行后每个声明输出均有值。
3. LLM：模型可用；每个提示词变量在输入区有绑定；raw_output 非空。
4. End：OutputType 为变量输出；输出引用真实上游字段。

## 五、最小运行验收

- 准备一条脱敏输入。
- 运行工作流。
- 成功信号：所有节点运行成功，End输出字段非空。

## 六、验收记录

记录：工作流名称、YAML SHA-256、目标工作空间和模型名称、导入日期、运行用例、各节点状态。
只有导入和运行两项都有证据，才能标记为公司端可部署。
