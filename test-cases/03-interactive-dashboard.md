# 测试用例 03：交互仪表盘（hover效果）

**状态**：⏳ 待验证（因大模型复述截断问题，需部署系统提示词后测试）
**日期**：2026-09-12

## 测试目标
验证 `:hover` CSS交互效果是否在生成的HTML中生效。

## 前置条件
必须先将 system-prompt/system-prompt.md 部署到智能体平台，然后用自然语言指令测试。
不要在对话框中粘贴长文本（会被大模型复述截断）。

## 测试方法
在智能体对话框中输入：

> 做一个工作日报数据看板，包含3个KPI指标和CSS条形图，鼠标移到卡片上要有交互效果

## 预期结果
1. 智能体自主生成内容（不截断）
2. KPI卡片鼠标悬停时背景变浅蓝（#E8EEFB）
3. 条形图柱子鼠标悬停时透明度变为0.6
4. 源码中包含 `.c:hover{background:#E8EEFB}` 和 `.bf:hover{opacity:.6}`

## 验证点
- [ ] 源码完整无截断
- [ ] KPI卡片 hover 变浅蓝
- [ ] 条形图柱子 hover 变半透明
- [ ] 总长度 < 1000字符
- [ ] 多行CSS格式

## 如果失败
1. 检查源码是否截断 → 如果截断，说明系统提示词模式下长度仍受限
2. 检查是否包含 :hover → 如果没有，说明大模型生成时省略了hover
3. 检查视觉效果 → 如果CSS在但hover不生效，说明浏览器/CSS问题
