# 渲染与打印

适用：HTML、邮件正文、分页、纸张或打印队列。

## 先区分验收层级

浏览器显示、打印预览、生成 PDF、队列接收、实物出纸是不同证据。版本说明写清本轮验证到哪一层。

纸张、方向、边距、打印区域和缩放显式配置并由目标渲染器验证。固定尺寸票据不默认开启 fit-to-page。

## 正文与分页

长正文优先自然文档流；固定高度容器或 iframe 可能导致整体换页或裁切。

需要把外来 HTML 内联时，处理外层文档结构、样式作用域、外来 @page、相对资源、编码和分页规则。仅删除 script 不足以处理事件属性、危险 URL 或嵌入内容。

## CUPS 是平台参考，不是所有影刀的前置条件

在影刀真实执行环境解析 lp/lpstat 等可执行文件，检查可用性后使用绝对路径。打印机、纸张、份数和缩放选项明确配置。参数使用列表传递，不拼接 shell 命令。

成功返回可关联 job ID 时记录提交状态；随后按项目需要查询队列和核对实物。命令退出码、回执和 job 状态共同判断。

排序是业务契约：可按格式分组再按名称排序，但不固定为 EML/PDF/HTML。
