## 逐轮详细记录

### T1：CSS注入基线测试 ✅

**输入**：3条CSS规则 + 2个div，class选择器，大写hex，`font-family: sans-serif`

**结果**：完全成功。源码显示 `<style>` 标签完整保留，CSS内容原样保留，`<div class="...">` 元素保留。

**确认**：`<style>` 标签可透传；class 选择器正常；大写十六进制正常；`font-family: sans-serif` 正常；原始 HTML div 保留。

### T2：极致效果v1 ❌

**输入**：5页瑞士风deck，含 `<section>`、`@keyframes`、`clamp()`、CSS Grid、单引号字体名

**结果**：生成文件空白一片。

**根因**：单引号 `'` 导致输入截断（在 `font-family: 'Inter'` 处断开）。

### T3：纯Markdown测试 ⚠️

**输入**：纯Markdown内容 + 顶部CSS，CSS使用元素选择器 h1/h2/h3 和小写十六进制

**结果**：内容渲染了，但CSS被损坏。

**损坏模式**：`h1` → `h 1`；`#f4f1ea` → `#f 4 f 1ea`；`#002FA7`（大写）→ 完好。

**确认**：元素选择器和小写hex不可用，必须用class选择器+大写hex。

### T4：Class选择器版 ⚠️

**输入**：全部class选择器 + 大写hex + 原始HTML div，无单引号

**结果**：用户反馈"效果很一般"。

### T5：仪表盘v1 ❌

**输入**：完整仪表盘，逗号分隔多字体名

**结果**：截断在 `font-family: Inter` 处。

**根因**：逗号分隔的多字体名导致截断。

### T6：仪表盘v2 ❌

**输入**：同上，改为 `font-family: sans-serif`

**结果**：截断在第一条CSS规则末尾。

**根因**：总长度 ~3000字符，超过输出长度限制。

### T7：迷你仪表盘 ✅

**输入**：压缩版仪表盘（3 KPI + 4条形图 + 3任务 + 2进度条），多行格式，~1000字符

**结果**：**完全成功**。源码55行完整保留。

**确认**：~1000字符是安全边界；多行格式必须；flexbox、CSS条形图、进度条、双栏布局全部正常。

### T8：增强仪表盘 ❌

**输入**：增强设计（hover+transition+badge），多行格式，~1600字符

**结果**：截断在第一条CSS规则。

### T9：1000字符压缩版 ❌

**输入**：压缩到960字符，但CSS全部单行压缩

**结果**：截断在第一条CSS规则。

**根因**：单行压缩格式本身导致截断。

## 根因分析

### 根因1：大模型复述截断（最主要）
用户在对话框粘贴长文本并说"转换成html"时，平台大模型需要将整段文本**复述**到 `md_text` 参数中。大模型在复述长文本时不稳定，经常提前停止。

**解决方案**：CSS模板放系统提示词，用户用自然语言描述需求，智能体自主生成内容。

### 根因2：单引号截断
单引号 `'` 被平台文本处理层当作字符串分隔符。

### 根因3：逗号多字体名截断
`font-family: Inter, Helvetica Neue, ...` 中的逗号可能被参数解析层误解。

### 根因4：小写字母+数字插空格
平台文本处理层在小写字母与数字相邻时插入空格，损坏元素选择器和小写十六进制。

### 根因5：单行CSS截断
所有CSS规则挤在一行时，即使总长度<1000字符也会截断。

## 已确认的安全规范（必须遵守）

### CSS规范
1. 全部使用 class 选择器，禁止 h1/h2/h3 等元素选择器
2. 全部使用大写十六进制颜色
3. 禁止使用单引号
4. font-family 只能用 `sans-serif`
5. 禁止 @keyframes、animation、transition
6. 禁止 CSS Grid（用 flex 替代）
7. 禁止 clamp()、calc()、var() 等CSS函数
8. 禁止渐变
9. 多行格式，每行一条CSS规则
10. 单次 md_text 总长度 < 1000字符（对话粘贴模式）

### HTML规范
1. 使用 `<div class="...">` 而非 `<h1>`/`<h2>`
2. 表格使用原生 `<table>`
3. 内联 style 可用于动态值
4. 不使用 `<img>`、`<section>`、`<article>`
5. 不使用 JavaScript

### 调用规范
1. CSS模板放在系统提示词中
2. 用户用自然语言描述需求，不粘贴长文本
3. 智能体自主生成内容，拼接CSS模板后调用 md_to_html
4. 多页内容拆分为多个文件
