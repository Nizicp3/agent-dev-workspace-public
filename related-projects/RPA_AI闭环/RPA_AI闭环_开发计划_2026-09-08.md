# RPA + AI 智能体完整闭环 · 开发计划

**日期：** 2026-09-08
**截止：** 2026-09-10（行内 AI 智能体比赛）
**基础资产：** 专业能力工作流生成智能体 + yingdao-rpa-designer skill + hiagent-workflow-builder skill

---

## 一、目标

以主 Agent 为底座，导入 yingdao-rpa-designer 能力，完成两条链路的闭环：

1. **RPA 开发设计链路**：主 Agent 生成 RPA 应用开发设计工作流——输入 RPA 需求，输出影刀开发方案
2. **每日邮件复盘链路**：用该工作流产出每日邮件复盘智能体方案——影刀 RPA 每日采集邮件+附件 → HiAgent 智能体分析整理 → 输出每日工作复盘

## 二、总体架构

```
HiAgent 平台（公司内网）
  主Agent：专业能力工作流生成智能体
    知识库：影刀RPA开发规则
    工作流①：RPA应用开发设计工作流
    产出 → 每日邮件复盘智能体配置方案
  每日邮件复盘智能体（对话型Agent）
    输入：邮件+附件结构化数据
    输出：每日复盘 + 明日工作安排
公司PC · 影刀RPA 每日邮件采集应用
  收件箱+已发送+附件 → 结构化输出 → 传HiAgent → 次日循环
```

## 三、开发阶段与交付物

### Phase 0：能力接入（9/8 上午）
- 将 yingdao-rpa-designer 的 SKILL.md + 6 篇参考文档整理为知识库文档
- 挂载到主 Agent 知识库
- 验收：主 Agent 能检索并正确回答影刀模块调用契约

### Phase 1：RPA 应用开发设计工作流（9/8 下午）
- 用 hiagent-workflow-builder 生成工作流 YAML（Start→Code→LLM→Code→End）
- Start：rpa_requirement + files
- Code 需求解析：提取 RPA 场景、操作对象、流程步骤
- LLM 方案生成：按影刀RPA开发规则输出四段式方案
- Code 结构校验：四段齐全性检查
- End：输出 rpa_design_plan
- 验收：HiAgent 导入成功，运行一条用例输出完整方案

### Phase 2：每日邮件复盘方案（9/9 上午）
用工作流①生成每日邮件复盘完整方案：
1. 邮件采集规范：范围、格式化规则、附件处理
2. AI 分析提示词：复盘模板
3. 数据通路设计：RPA 输出 → HiAgent 的三种方式
4. 复盘智能体配置：对话型 Agent 提示词 + 知识库 + 工作流挂载

### Phase 3：HiAgent 配置 + 影刀 RPA 应用（9/9 下午，可并行）
- 按方案配置每日邮件复盘智能体
- 影刀 RPA 采集应用：邮件+附件采集、结构化输出
- 验收：脱敏邮件数据跑通输入 → 复盘产出

### Phase 4：闭环演示与比赛材料（9/9 晚 - 9/10）
- 端到端演示：RPA 采集样例 → 复盘智能体 → 复盘文档
- 录屏 + 功能说明 + 比赛提交材料打包

## 四、风险与待验证点
