# 专业能力工作流生成智能体
## —— 让每个运营人都能「造」出自己的 AI 智能体

**参赛赛道：** 银行运营条线 · AI 智能体比赛
**项目形态：** 单主 Agent 对话型 + 七工作流双路线生成引擎 + RPA×AI 业务闭环
**一句话定位：** 我们做的不是一个智能体，而是一条智能体生产线——用 AI 造 AI。

---

## 〇、项目速览（30 秒电梯陈述）

过去，开发一个智能体需要技术团队花数周：写提示词、搭工作流、调模型、测链路、写文档。现在，业务人员只需用一句话描述需求，我们的系统就会自动产出：可导入平台的工作流、可运行的 RPA 代码、部署 SOP 和验收清单——全程零代码、可测试、可复制。

## 一、项目背景与痛点

### 1.1 运营条线的重复劳动黑洞
每日邮件复盘与待办整理、报表汇总、流程跟踪、监管数据搬运……占用大量精力，容易出错、难以追溯。

### 1.2 数字化能力断层
一线运营人员最懂业务痛点，但智能体建设需要提示词工程、工作流编排等技能；技术团队不懂业务细节，来回沟通成本高。

### 1.3 智能体建设一次性困局
常规做法是一个需求 → 一个智能体 → 从头开发。知识和经验无法沉淀复用，建设成本居高不下。

### 1.4 RPA 与 AI 割裂
流程自动化擅长执行，AI 智能体擅长分析，但两者往往分开建设、无法打通。采集、分析、决策、执行无法形成闭环。

---

## 二、核心创意

### 创意一：用 AI 造 AI —— 工作流工厂元能力
本项目不是解决某单一业务的智能体，而是一个能生成智能体的智能体。用户输入业务需求，系统自动完成：需求理解 → 结构校验 → 方案编排 → 工作流生成 → 排障修复 → 测试验收 → 部署交付。

### 创意二：双路线生成 —— 一个需求，两个成品

| 路线 | 产物 | 角色 |
|---|---|---|
| 路线 A：工作流生成 | HiAgent 可导入的 YAML 工作流 | 智能体的脑——分析、判断、决策 |
| 路线 B：影刀生成 | 影刀 RPA 可运行的 Python 代码 | 自动化的手——采集、执行、搬运 |

脑与手同时交付，天然闭环。

### 创意三：Skill 拆解 —— 让专家经验可复制
工作流 06 Skill 拆解：输入一个专业能力包，输出一套结构化的、可检索的规则知识库。解决经验在老师傅脑子里的传承难题。

### 创意四：真实场景闭环 —— 每日邮件复盘零门槛落地
影刀 RPA 每日自动采集邮件+附件 → HiAgent 智能体自动分析整理 → 输出每日工作复盘 + 明日工作安排。生成即可用、可用即见效。

### 创意五：面向真实战场的工程化韧性
平台输入框会静默吞掉特殊字符（星号、下划线、等号），导致提示词粘贴后功能静默失效。我们为此发明了零禁忌字符提示词工程：2767 字符定稿版，纯 Markdown 语法，全平台粘贴零损耗。

双保险容错设计：主提示词内置环境配置默认值；工作流编译节点参数改为可选，缺失时自动回退默认值。

## 三、系统架构与技术方案

### 3.1 总体架构

主 Agent（对话型）驱动 7 个专业工作流：01 材料识别 → 02 需求校验 → 03 方案整理 → 04 YAML 生成 → 05 排障修复 → 06 Skill 拆解 → 07 影刀生成。

双路线输出：路线 A → HiAgent 可导入工作流 YAML；路线 B → 影刀 RPA 可运行 Python 代码。

### 3.2 七个工作流详解

| # | 工作流 | 作用 | 亮点 |
|---|---|---|---|
| 01 | 材料识别 | 解析用户上传的需求文档，抽取关键信息 | 非结构化材料变结构化输入 |
| 02 | 需求校验 | 检查需求完整性，返回校验结果 | 从源头拦截坏需求 |
| 03 | 方案整理 | 按规则编排技术方案：四段式 | 输出结构化标准方案 |
| 04 | YAML 生成 | 生成 HiAgent 可导入工作流 YAML | 路线 A 核心：双保险容错 |
| 05 | 排障修复 | 对工作流运行错误进行诊断 | 让生成产物可自愈 |
| 06 | Skill 拆解 | 把专业能力包拆解为规则知识库 | 专家经验资产化 |
| 07 | 影刀生成 | 生成影刀 RPA 可运行 Python 代码 | 路线 B 核心 |

### 3.3 契约层与质量保障
每个生成的工作流都经过单节点 → 工作流 → 端到端三层验收。

### 3.4 数据通路与容灾设计
API 直连（待验证）、文件传输（已实测）、手动粘贴（已实测）、Web Demo（零依赖可运行）。

## 六、应用价值与推广前景

### 6.1 四大核心价值
提效：智能体建设周期从数周压缩到小时级。

### 6.2 推广场景地图
每日邮件复盘（已落地）→ 报表自动汇总 → 监管数据搬运 → 流程跟踪提醒 → 客户服务辅助。
